# UN_DataPortal-KPI1 (Vite + React)

## Run locally
```bash
npm install
npm run dev
```

## GitHub Pages
This project is configured for:
- User/org: `Gisspecialist`
- Repo: `UN_DataPortal-KPI1`
- Site base path: `/UN_DataPortal-KPI1/` (already set in `vite.config.js`)

Add the workflow `.github/workflows/deploy.yml`, then in GitHub:
**Settings → Pages → Source = GitHub Actions**
